# Programación en Java

## 15. ¿Cuáles son los tipos de datos primitivos en Java?
Los tipos de datos primitivos en Java sirven para guardar información básica como números,
letras o valores verdaderos y falsos. Algunos ejemplos son int para números enteros,
double para números decimales, char para caracteres y boolean para valores verdadero o falso.

---

## 16. ¿Cómo funcionan las estructuras de control de flujo en Java?
Las estructuras de control permiten que el programa tome decisiones o repita acciones.
Por ejemplo, con if y else el programa decide qué hacer según una condición, con switch
elige entre varias opciones y con los bucles se repiten instrucciones varias veces.

---

## 17. ¿Por qué es importante usar nombres significativos?
Usar nombres claros para las variables y métodos ayuda a entender mejor el programa.
Esto hace que el código sea más fácil de leer, corregir y mantener en el tiempo.

---

## 18. ¿Qué es la Programación Orientada a Objetos?
La Programación Orientada a Objetos es una forma de programar donde se usan objetos que
representan cosas reales. Cada objeto tiene datos y acciones que puede realizar.

---

## 19. ¿Cuáles son los cuatro pilares de la Programación Orientada a Objetos?
Los cuatro pilares son:
- Encapsulamiento
- Herencia
- Polimorfismo
- Abstracción  
Estos ayudan a organizar mejor el código y a reutilizarlo.

---

## 20. ¿Qué es la herencia y cómo se usa en Java?
La herencia permite que una clase use características de otra clase. En Java se utiliza
la palabra extends para que una clase herede métodos y atributos de otra.

---

## 21. ¿Qué son los modificadores de acceso en Java?
Los modificadores de acceso controlan desde dónde se puede acceder a una clase, método
o variable. Los más comunes son public, private y protected.

---

## 22. ¿Qué es una variable de entorno y por qué es importante?
Una variable de entorno es un valor que guarda el sistema y que los programas pueden usar.
Son importantes porque permiten configurar programas sin cambiar el código.
